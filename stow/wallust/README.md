# Wallust

![Wallust](../../docs/capturas/hyprland.png)

Genera la paleta a partir del fondo y la aplica a Hyprland, hyprlock, Waybar, Rofi, kitty, ghostty, cava, Quickshell y Code - OSS.

## Qué incluye

- `wallust.toml`: plantillas y destinos.
- `templates/`: una plantilla por aplicación.

## Atajos

- Super+U: elegir fondo (recolorea todo)

## Instalar solo esto

```bash
./install.sh --only wallust
```
