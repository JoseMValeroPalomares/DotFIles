# Kitty

![Kitty](../../docs/capturas/kitty.png)

Terminal con FantasqueSansM Nerd Font 14, fondo translúcido (0,55) y acentos de wallust; abre tmux en cada ventana.

## Qué incluye

- `kitty.conf`.
- `kitty-themes/`: temas (el de wallust se genera solo).
- Semillas: `wallust-accents.conf` y `kitty-themes/01-Wallust.conf`.

## Atajos

- Super+Enter: nueva terminal
- Temas de kitty: menú de ajustes rápidos (Super+Shift+E)

## Instalar solo esto

```bash
./install.sh --only kitty
```

Funciona mejor junto a: fonts. Sin ellos no falla nada, solo deja de responder lo que dependa de ellos.
