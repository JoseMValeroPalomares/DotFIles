# Herramientas de terminal

![Herramientas de terminal](../../docs/capturas/cli.png)

Configs de btop, fastfetch, cava, ghostty, wezterm, peaclock, swappy, yad, clangd y git.

## Qué incluye

- `.config/<herramienta>/…`.
- Semillas: config de cava y colores de ghostty (los genera wallust), qalculate, mousepad, xarchiver, pavucontrol y nwg-displays.

## Instalar solo esto

```bash
./install.sh --only cli
```
