# Scripts propios

`~/.local/bin/brillo` (brillo del portátil y de monitores externos por DDC) y `screenshot-ocr` (selecciona una zona y copia el texto).

## Qué incluye

- `.local/bin/brillo`, `.local/bin/screenshot-ocr`.

## Instalar solo esto

```bash
./install.sh --only bin
```
