# Quickshell (overview)

![Quickshell (overview)](../../docs/capturas/quickshell.png)

Vista general de escritorios con miniaturas en vivo, colores de wallust y teclas 1-0.

## Qué incluye

- `overview/`: el overview en QML.
- `legacy/`: la versión anterior.
- Semillas: `qml_color.json` y `overview/colors.json` (wallust).

## Atajos

- Super+A: abrir/cerrar el overview

## Instalar solo esto

```bash
./install.sh --only quickshell
```

Funciona mejor junto a: hyprland, wallust. Sin ellos no falla nada, solo deja de responder lo que dependa de ellos.
