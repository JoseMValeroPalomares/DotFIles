# Spotify + Spicetify

![Spotify + Spicetify](../../docs/capturas/spicetify.png)

Spotify con el tema StarryNight y el marketplace; el `.desktop` lo lanza en Wayland nativo.

## Qué incluye

- `.local/share/applications/spotify.desktop`.
- La configuración se aplica con `scripts/post/spicetify.sh` (referencia en `scripts/spicetify/config-xpui.ini.ref`).

## Atajos

- Tras actualizar Spotify: `~/dotfiles/scripts/post/spicetify.sh`

## Instalar solo esto

```bash
./install.sh --only spicetify
```
