# Tema GTK/Qt

![Tema GTK/Qt](../../docs/capturas/theme.png)

Catppuccin Mocha en GTK 3/4 (mauve), Kvantum y qt5ct/qt6ct; iconos bessurf-dark-purple y cursor catppuccin-mocha-lavender.

## Qué incluye

- `stow/theme`: temas de Kvantum y colores/QSS de qt5ct y qt6ct.
- `seeds/theme`: `settings.ini` de GTK 3/4, `.gtkrc-2.0`, `kvantum.kvconfig`, `qt5ct.conf`, `qt6ct.conf`, xsettingsd, nwg-look, iconos bessurf y temas Flat-Remix GTK.

## Instalar solo esto

```bash
./install.sh --only theme
```
