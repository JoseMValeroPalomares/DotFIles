# Code - OSS

![Code - OSS](../../docs/capturas/code-oss.png)

Catppuccin Noctis Mocha + iconos Catppuccin, FiraCode Nerd Font, y un tema local que toma los acentos de wallust.

## Qué incluye

- `User/settings.json`, `keybindings.json`, `tasks.json` y `snippets/`.
- `.vscode-oss/extensions/local.wallust-theme-1.0.0`: tema propio (no está en Open VSX).
- Las 16 extensiones restantes se instalan desde `packages/code-extensions.txt`.

## Instalar solo esto

```bash
./install.sh --only code-oss
```

Funciona mejor junto a: wallust. Sin ellos no falla nada, solo deja de responder lo que dependa de ellos.
