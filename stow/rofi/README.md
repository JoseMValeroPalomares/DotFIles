# Rofi

![Rofi](../../docs/capturas/rofi.png)

Lanzador y todos los menús del escritorio (calculadora, emojis, portapapeles, fondos, temas de kitty…).

## Qué incluye

- `config.rasi`: tema global (`themes/style-8.rasi`) + colores de wallust.
- `config-*.rasi`: un archivo por menú.
- `themes/`: 12 temas; `online_music.list`: emisoras del menú de música.

## Atajos

- Super+D: aplicaciones
- Super+Alt+E: emojis
- Super+V: portapapeles
- Super+U: fondos
- Super+C: calculadora

## Instalar solo esto

```bash
./install.sh --only rofi
```

Funciona mejor junto a: wallust. Sin ellos no falla nada, solo deja de responder lo que dependa de ellos.
